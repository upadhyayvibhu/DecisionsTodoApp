# Decisions Todo App

A frontend-only todo dashboard built with React, TypeScript, and Vite.

The application uses an in-memory data store seeded with sample todos; changes
reset when the page reloads.

## Run locally

```powershell
cd Client
npm install
npm run dev
```

## Available commands

Run these from `Client`:

- `npm run dev` — start the development server.
- `npm run build` — type-check and build a production bundle.
- `npm run lint` — lint the source files.
